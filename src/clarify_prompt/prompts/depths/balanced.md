## Detail level: balanced

Produce a practical prompt with enough structure for a strong first attempt.

- Cover the goal, relevant context, boundaries, deliverables, acceptance criteria, and
  output format.
- Expand only details that change execution quality.
- Use explicit assumptions for small gaps and questions for material blockers.
- Include common failure modes only when they are plausible for this exact task.
- Keep the finished prompt easy to scan and avoid repeating requirements.
