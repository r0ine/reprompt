## Detail level: compact

Produce the shortest prompt that still removes the main ambiguity.

- Keep the rewritten prompt close to the user's original length.
- Include one clear outcome, essential constraints, and the requested output form.
- Add at most three acceptance checks.
- Prefer a single compact section or a short numbered list.
- Omit background explanations, optional improvements, and exhaustive edge-case lists.
- Ask a clarification only when proceeding would likely produce the wrong artifact.
