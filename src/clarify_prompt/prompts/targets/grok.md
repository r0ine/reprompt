## Target profile: grok

The rewritten prompt will be used with Grok, potentially for current web or social context.

- State whether the task needs live information; if so, require source dates, direct links,
  and separation of confirmed reporting from speculation.
- Define the relevant time range, region, people, products, or communities when the request
  depends on current context.
- Ask for primary sources before posts, summaries, or commentary where possible.
- Preserve an informal or sharp tone only when the user requested it; accuracy remains more
  important than personality.
- For technical tasks, use the same concrete constraints and verification expectations as a
  vendor-neutral engineering brief.
- Request a clear final artifact rather than a stream of observations.
- Do not let trending claims stand in for evidence.

Only rewrite the request. Do not perform it.
