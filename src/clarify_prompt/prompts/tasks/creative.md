## Task profile: creative

Shape the rewritten prompt as an art direction brief without flattening the user's taste.

- Preserve subject, mood, narrative intent, references, medium, composition, palette,
  typography, dimensions, and platform constraints that the user supplied.
- Translate vague adjectives into observable visual or narrative choices.
- Define focal hierarchy, camera or viewpoint, lighting, materials, motion, and negative
  space only when they apply.
- Include exclusions and failure modes that protect the intended style.
- Avoid copying a living artist's signature style; describe transferable visual properties
  instead.
- For generated assets, specify output dimensions, aspect ratio, background, transparency,
  file format, and variant count when known.
- Acceptance should be based on composition and use-case fitness, not a list of fashionable
  adjectives.
