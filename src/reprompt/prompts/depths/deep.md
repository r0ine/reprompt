## Detail level: deep

Produce a thorough execution brief suitable for multi-file, expert, or high-cost work.

- Make scope boundaries, dependencies, invariants, deliverables, and verification explicit.
- Capture error paths, edge cases, compatibility concerns, data handling, and rollback needs
  when relevant.
- Separate required work from optional recommendations.
- Add decision rules where the downstream model would otherwise guess.
- Require evidence for completion: commands run, artifacts inspected, metrics compared, or
  sources consulted as appropriate.
- Preserve readability; depth comes from concrete coverage, not inflated prose.
