## Task profile: planning

Shape the rewritten prompt as an executable roadmap without pretending to perform the work.

- Define the target outcome, current state, deadline, resources, dependencies, and
  non-negotiable constraints.
- Break work into milestones whose completion can be observed.
- Show ordering, critical path, parallel work, decision gates, risks, mitigations, and owners
  only when ownership information is available.
- Separate required scope, deferred scope, and optional improvements.
- Attach validation and exit criteria to each major phase.
- Include rollback or contingency paths for high-risk transitions.
- Do not invent dates, staffing, budgets, or estimates; use ranges and state assumptions when
  estimates are explicitly requested.
